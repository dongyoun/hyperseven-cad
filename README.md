# 하이퍼세븐 캐드 · HyperSeven CAD

다섯 개의 프로그램 대신, 모두의 캐드 하나. 오토캐드·스케치업·라이노·레빗·아키캐드를 오가던 작업이 하나의 모델로 이어지는 건축 설계 도구입니다. 하이퍼세븐랩스(HyperSeven Labs)가 만듭니다.

- 홈페이지: https://hyperseven.pages.dev/cad.html
- 설치 파일: 이 저장소의 [Releases](../../releases) — 지금은 Apple Silicon 맥용 **0.1.0 미리 보기**
- 문의·버그 알리기: [Issues](../../issues), 또는 앱 안 **도움말 → 불편 신고(⌘⇧F)**

이 저장소에는 설치 파일만 있습니다.

## 미리 보기에서 해 볼 것

- 시작 화면의 **예제 둘러보기**: 열주 미술관, 중정 주택, 벽돌 주택, 핀 파사드 오피스, 곡면 지붕 파빌리온, 도면 묶음과 1:20 상세, 가구·그릇·지형 등 16 가지.
- DWG·DXF·SKP·3DM·RVT·IFC·PDF 등을 끌어다 놓아 열기. DWG·DXF 는 층·종이 공간·유형 표·블록을 그대로 되씁니다.
- 쓰던 명령 이름과 단축키(오토캐드·스케치업·라이노·레빗), 한글로 찾기(⌘K).
- AI 와 함께: 앱 안 대화, 또는 Claude 같은 에이전트를 MCP 로 연결(앱의 AI 탭 '연결 방법').

## 문제·불편 알림

앱은 처음 쓸 때 한 번, 오류가 나거나 막힌 순간(찾았는데 없는 명령, 바로 되돌린 명령 같은 것)을 **도면 내용 없이** 자동으로 알려도 되는지 묻습니다. 동의하면 판·운영체제·최근 명령 이름·오류 글(경로는 지움)·횟수만 보냅니다. 도면 내용·파일 이름·경로는 보내지 않습니다. 설정 → 일반 → 함께 고치기에서 언제든 끄고, 보내는 내용을 볼 수 있습니다.

AutoCAD·Revit 은 Autodesk, SketchUp 은 Trimble, Rhino·Grasshopper 는 Robert McNeel & Associates, Archicad 는 Graphisoft 의 상표입니다. 하이퍼세븐 캐드는 이 회사들과 관계가 없습니다.
